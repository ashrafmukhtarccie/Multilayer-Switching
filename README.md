# Multilayer Switching

## Overview

This lab demonstrates how multilayer switches provide Layer 3 routing between different VLANs.

## Objectives

* Configure VLANs
* Configure SVIs
* Enable IP routing
* Configure inter-VLAN communication
* Verify connectivity

## Tools

* Cisco Packet Tracer
* Cisco IOS

## Outcome

Configured a multilayer switch to perform routing between network segments.
